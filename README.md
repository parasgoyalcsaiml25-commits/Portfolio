# PortfolioGenerator

AI Resume Portfolio Generator built with Flask and Google Gemini.

A complete web application that turns any resume (PDF, TXT, JPG, PNG, WEBP) into a responsive, customizable developer or designer portfolio website.

## Features
- **AI-Powered Resume Extraction**: Extracts skills, experience, projects, education, and contact links using Google Gemini.
- **4 Themes/Templates**: Simple, Designer, Developer, Corporate.
- **Customization**: Accent color picker, template switcher, profile picture upload.
- **Export Options**: 
  - Standalone HTML download
  - PDF export
  - GitHub Pages deployment package (ZIP)
